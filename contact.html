To set up the Tally form:

  2. Create a new form using Client_Enquiry_Form.docx as the field reference (in Master_Templates/)
  3. Connect Tally to your Notion workspace for automatic lead capture
  4. In form settings → Embed → copy the iframe code
  5. Replace this placeholder block with the Tally embed code
  6. In Tally design settings: set background to #111611 and accent to #4caf7d
