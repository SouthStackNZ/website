og-image.png
------------
Create a 1200x630px image for social sharing previews.
This is what appears when someone shares southstack.co.nz on LinkedIn, Facebook, iMessage, X etc.

Suggested content:
- Dark green background (#0a0f0a)
- SouthStack logo/name centered
- Tagline: "Web Development, South Island NZ"
- Keep it simple and on-brand

Tools to create it:
- Figma (free)
- Canva (free)
- Once created, save as og-image.png and add to repo root
